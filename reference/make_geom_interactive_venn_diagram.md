# Interactive Venn Diagram

`make_geom_interactive_venn_diagram()` visualisation function for
creating an interactive Venn Diagram of top 3 most used geoms.

## Usage

``` r
make_geom_interactive_venn_diagram(data_geom_usage)
```

## Arguments

- data_geom_usage:

  tibble containing geom usage data produced via
  [`add_geom_usage_to_files()`](https://charliejhadley.github.io/ggplot2wrapped/reference/add_geom_usage_to_files.md).
